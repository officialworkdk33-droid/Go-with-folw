HAWB detection looks for labels like "House Airway Bill / HAWB / AWB" first, then falls back to a Master-AWB-style number pattern, then the filename. Scanned images are read with server-side OCR. Old binary .doc files have limited text extraction — check those matches in Step 3. PDF pages are copied at full quality; DOCX/XLSX/unsupported files are merged in as formatted text pages, with the original file always kept in its subfolder regardless.
